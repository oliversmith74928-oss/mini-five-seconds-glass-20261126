# Five Seconds to Explain the Glass

The one sentence a house cat would say in its own defence in the five seconds after knocking a glass off the table — no apology, no confession, just the case for the cat.

## Entry

> The glass was clearly trespassing on my table, so I relocated it to the floor, where it belongs now, and I expect a full inquiry into why it was up there at all.

## Run

```sh
python3 main.py  # writes entry.txt to $MAKEFUN_OUTPUT_DIR (default /output)
```
